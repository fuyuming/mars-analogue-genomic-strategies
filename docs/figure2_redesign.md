# Alternative Figure 2 layout

This separately named candidate redraws the completed core65 display trees and lineage means. The default manuscript figure is retained. No new genomes or in-progress trees are represented.

Run from the repository root:

```sh
python scripts/figures/redesign_lineage.py --repo . --out figures_out/redesign
```

The output contains PDF/SVG/600 dpi PNG, all 711 plotted values, selected labels and input hashes. The topology, branch depths, row order and module means are unchanged. Tree-to-matrix alignment guides, sampling counts and a shared sequential scale improve navigation. Genome counts and source-catalogue counts are sampling context, not independent ecological replicates. Archived display representatives do not encode all within-block diversity.
